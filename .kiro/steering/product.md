# Product Overview

Art Admin is a full-stack admin management system with a Vue 3 frontend and Go backend.

## Core Features

- **User & Role Management**: Authentication, authorization, RBAC permissions
- **System Administration**: Menus, departments, dictionaries, operation logs
- **Learning System**: Subjects, materials, AI-generated content via DeepSeek/Dify
- **Mood Tracking**: Mood records, meditation, journaling, achievements
- **Travel Planning**: Roadbooks, waypoints, AI trip planning
- **Chat System**: Real-time chat rooms via WebSocket
- **Project Management**: Projects, tasks, Gantt charts, templates
- **XHS Integration**: Xiaohongshu content summarization

## Target Users

Admin dashboard for internal business operations with multi-language support (Chinese/English).
