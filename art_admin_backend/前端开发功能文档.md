# 情绪健康管理系统 - 前端开发完整指南

## 1. 系统概述

### 1.1 产品定位
本系统是一款**个人情绪健康管理应用**，帮助用户：
- 📊 **记录和追踪**日常情绪变化
- 🧘 **冥想练习**缓解压力和焦虑
- 📝 **日记写作**表达和整理内心想法
- 🤖 **AI智能分析**提供个性化建议
- 🎯 **目标设定**培养健康习惯
- ✅ **打卡激励**保持持续性

### 1.2 核心价值链
```
记录情绪 → 发现规律 → 冥想调节 → 日记反思 → AI分析 → 持续改善
```

### 2.4 目标与打卡业务流程

```
┌─────────────────────────────────────────────────────────────────┐
│                         目标设置                                │
└─────────────────────────────────────────────────────────────────┘
选择目标类型 → 设置目标值 → 选择周期(每日/每周/每月) → 创建目标

目标类型:
- mood_record: 每日记录情绪 (例: 每天记录3次)
- meditation: 每日冥想练习 (例: 每天冥想2次)
- journal: 每日写日记 (例: 每天写1篇)

┌─────────────────────────────────────────────────────────────────┐
│                         打卡系统                                │
└─────────────────────────────────────────────────────────────────┘

        ┌─────────────────────────────────────┐
        │           每日打卡入口               │
        │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐   │
        │  │情绪 │ │冥想 │ │日记 │ │通用 │   │
        │  │ ✓  │ │ ○  │ │ ○  │ │ ○  │   │
        │  └─────┘ └─────┘ └─────┘ └─────┘   │
        │       今日已打卡 1/4                │
        └─────────────────────────────────────┘

打卡规则:
1. 同一类型每天只能打卡一次
2. 完成对应任务自动打卡(记录情绪→情绪打卡)
3. 通用打卡需手动完成
4. 连续打卡天数自动计算

连续打卡计算:
- 从今天往前检查，遇到未打卡日期停止
- 如果今天未打卡但昨天已打卡，从昨天开始计算
- 支持按类型单独统计
```

## 6. 数据库表(需创建)

```sql
-- 冥想收藏表
CREATE TABLE meditation_favorites (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  content_id BIGINT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY idx_user_content (user_id, content_id)
);

-- 冥想播放记录表
CREATE TABLE meditation_play_records (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  content_id BIGINT NOT NULL,
  duration INT DEFAULT 0,
  progress DECIMAL(5,2) DEFAULT 0,
  completed BOOLEAN DEFAULT FALSE,
  last_played_at DATETIME,
  play_count INT DEFAULT 1,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 用户目标表
CREATE TABLE user_goals (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  goal_type VARCHAR(50) NOT NULL,
  target_value INT NOT NULL,
  period VARCHAR(20) NOT NULL,
  is_active BOOLEAN DEFAULT TRUE,
  start_date DATETIME NOT NULL,
  end_date DATETIME,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 用户打卡表
CREATE TABLE user_checkins (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  checkin_date VARCHAR(10) NOT NULL,
  checkin_type VARCHAR(50) NOT NULL,
  note TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY idx_user_date_type (user_id, checkin_date, checkin_type)
);

-- 目标进度表
CREATE TABLE goal_progress (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  goal_id BIGINT NOT NULL,
  progress_date VARCHAR(10) NOT NULL,
  current_value INT DEFAULT 0,
  is_completed BOOLEAN DEFAULT FALSE,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
