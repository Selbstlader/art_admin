## ⏱️  时间线

```
0s      用户点击 [生成教材]
        ↓
0.1s    前端发送 API 请求
        ↓
0.2s    后端验证 Token
        ↓
0.3s    查询学科信息
        ↓
0.5s    开始 Dify 检索
        ↓
3s      Dify 返回知识片段
        ↓
3.5s    构建 RAG Prompt
        ↓
4s      调用 DeepSeek API
        ↓
        ... AI 思考中 ...
        ↓
50s     DeepSeek 返回结果
        ↓
50.5s   解析 JSON
        ↓
51s     保存到数据库
        ↓
51.5s   返回给前端
        ↓
52s     前端渲染展示
        ↓
        ✅ 用户看到完整教材
```

## 🔄 数据流向

```
用户输入 → 前端 → 后端 API → Service → Dify → Service → DeepSeek → Service → 数据库 → 前端 → 用户
   ↑                                                                                              ↓
   └──────────────────────────────────── 完整闭环 ────────────────────────────────────────────────┘
```

## 📊 关键指标

| 环节 | 耗时 | 数据量 | 说明 |
|------|------|--------|------|
| 前端请求 | 0.1s | 100B | JSON 请求 |
| Token 验证 | 0.1s | - | JWT 解析 |
| 数据库查询 | 0.1s | 1KB | 学科信息 |
| Dify 检索 | 2-3s | 2-5KB | 知识片段 |
| Prompt 构建 | 0.5s | 5KB | 文本拼接 |
| DeepSeek 生成 | 30-60s | 10-20KB | AI 生成 |
| JSON 解析 | 0.5s | 10-20KB | 数据处理 |
| 数据库保存 | 0.5s | 10-20KB | INSERT |
| 返回前端 | 0.5s | 10-20KB | HTTP 响应 |
| **总计** | **40-70s** | **~30KB** | **端到端** |
