### 后端 → 前端字段映射

后端响应（`response/menu_res.go`）：
```go
type MenuResponse struct {
    ID        int64           `json:"id"`
    Name      string          `json:"name"`        // 路由名称 → 前端 label
    Path      string          `json:"path"`
    Component string          `json:"component"`
    Redirect  string          `json:"redirect"`
    Meta      MenuMeta        `json:"meta"`
    Children  []*MenuResponse `json:"children"`
}

type MenuMeta struct {
    Title      string       `json:"title"`        // 显示名称 → 前端通过meta.title显示
    Icon       string       `json:"icon"`
    IsHide     bool         `json:"isHide"`
    IsHideTab  bool         `json:"isHideTab"`
    KeepAlive  bool         `json:"keepAlive"`
    FixedTab   bool         `json:"fixedTab"`
    IsFullPage bool         `json:"isFullPage"`
    AuthList   []AuthButton `json:"authList"`
}
```

## 🔧 关键配置

### 1. 数据库表结构
表名：`sys_menu`

主要字段：
- `name` (varchar) - 路由名称/权限标识（对应前端label）
- `title` (varchar) - 菜单显示名称（对应前端name）
- `path` (varchar) - 路由地址
- `component` (varchar) - 组件路径
- `is_enable` (tinyint) - 是否启用
- `is_menu` (tinyint) - 是否菜单（区分按钮）
- `sort` (int) - 排序

### 2. Service层字段转换

文件：`internal/service/menu_service.go`

**创建菜单时的转换：**
```go
menu := &model.Menu{
    Name:  req.Label,   // 前端label → 后端Name（路由名称）
    Title: req.Name,    // 前端name → 后端Title（显示名称）
    // ... 其他字段直接映射
}
```

**响应时的转换：**
```go
node := &response.MenuResponse{
    ID:        menu.ID,
    Name:      menu.Name,      // 后端Name → 响应name（路由名称）
    Path:      menu.Path,
    Component: menu.Component,
    Meta: response.MenuMeta{
        Title: menu.Title,     // 后端Title → 响应meta.title（显示名称）
        // ... 其他字段
    },
}
```

### 3. 按钮权限字段映射

数据库表：`sys_button`
- `auth_name` (varchar) - 权限名称（对应前端title）
- `auth_label` (varchar) - 权限标识（对应前端authMark）
- `auth_icon` (varchar) - 权限图标
- `auth_sort` (int) - 权限排序
- `is_enable` (tinyint) - 是否启用

## ⚠️ 注意事项

1. **字段命名差异**：
   - 前端的 `name` 字段表示菜单的显示名称（如"仪表盘"）
   - 后端的 `Name` 字段存储的是路由名称（如"Dashboard"）
   - 通过Service层进行转换，确保正确映射

2. **删除接口调用方式**：
   - 后端使用路径参数：`DELETE /api/menu/delete/:id`
   - 前端调用：`fetchDeleteMenu(id)` 自动拼接到URL中

3. **启用状态字段**：
   - 数据库字段从 `enabled` 改为 `is_enable`
   - 确保所有查询都使用新字段名

4. **按钮权限字段**：
   - 数据库字段从 `title/auth_mark` 改为 `auth_name/auth_label`
   - 响应时需要映射回前端期望的 `title/authMark` 格式
