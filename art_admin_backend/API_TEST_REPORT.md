## 详细测试用例

### 1. 项目模板管理

#### 1.1 获取模板列表 ✅
- **接口**: `GET /api/project/template/list`
- **参数**: `page=1&pageSize=10`
- **结果**: 成功返回空列表
- **响应时间**: ~8ms

#### 1.2 创建项目模板 ✅
- **接口**: `POST /api/project/template`
- **功能**: 创建包含3个任务的软件开发模板
- **结果**: 成功创建模板ID=1,并创建3个模板任务
- **验证**: 
  - 模板基本信息正确
  - 任务自动关联到模板
  - 里程碑标记正确

### 2. 项目管理

#### 2.1 从模板创建项目 ✅
- **接口**: `POST /api/project/from-template`
- **功能**: 从模板ID=1创建"电商平台开发项目"
- **结果**: 
  - 成功创建项目(PROJ-2025-001)
  - 自动创建3个任务
  - 任务时间根据项目开始日期自动计算
  - 项目成员自动添加
- **响应时间**: ~40ms

#### 2.2 获取项目列表 ✅
- **接口**: `GET /api/project/list`
- **结果**: 成功返回1个项目
- **数据完整性**: 所有字段正确返回

#### 2.3 获取项目统计 ✅
- **接口**: `GET /api/project/statistics`
- **结果**: 
  - 总项目数: 1
  - 进行中: 0
  - 已完成: 0
  - 超期: 0

### 3. 任务管理

#### 3.1 获取甘特图数据 ✅
- **接口**: `GET /api/project/task/gantt?projectId=1`
- **结果**: 
  - 返回4个任务(包括子任务)
  - 任务类型正确(milestone/task)
  - 时间范围正确
  - 依赖关系正确
- **数据格式**: 完全符合DHTMLX Gantt格式

#### 3.2 手动创建任务 ✅
- **接口**: `POST /api/project/task`
- **功能**: 在"开发实现"下创建子任务"前端开发"
- **结果**: 
  - 成功创建子任务(ID=4)
  - 父子关系正确(parentId=3)
  - 预估工时记录正确

#### 3.3 创建任务依赖 ✅
- **接口**: `POST /api/project/task/dependency`
- **功能**: 创建"需求分析"→"系统设计"的FS依赖
- **结果**: 成功创建依赖关系
- **验证**: 甘特图数据中包含依赖信息

#### 3.4 批量更新任务 ✅
- **接口**: `PUT /api/project/task/batch`
- **功能**: 模拟甘特图拖拽,批量更新2个任务
- **结果**: 
  - 任务2: 时间调整,进度更新为30%
  - 任务3: 时间调整,进度更新为10%
- **响应时间**: ~4ms

#### 3.5 获取任务列表 ✅
- **接口**: `GET /api/project/task/list?projectId=1`
- **结果**: 返回4个任务,进度和时间已更新
